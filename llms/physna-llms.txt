# Physna

> Physna is a geometric search and 3D deep-learning platform that searches, compares, analyzes, and organizes 3D models and physical parts by their actual geometry. The Physna Public API (v2) is a JSON REST API for ingesting 3D models and running geometric, part-in-part, scan, visual, and image-based similarity search, plus collections, folders, metadata, assembly trees, and match reports. It is authenticated with OAuth 2.0 via Physna's Okta authorization server.

This llms.txt was generated by the API Evangelist enrichment pipeline from the provider's public OpenAPI and documentation; Physna does not publish its own llms.txt (the marketing site returns an SPA shell for /llms.txt).
